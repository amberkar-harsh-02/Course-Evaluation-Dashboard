# Professor Portal: Quick Start Guide

Welcome to the new **Course Evaluation Dashboard**! 

This portal was built to make reviewing your end-of-semester course evaluations as simple and insightful as possible. Instead of digging through messy spreadsheets or long PDF reports, this tool automatically organizes your student feedback, highlights key metrics, and presents student comments in a clean, easy-to-read format.

Here is a quick walkthrough on how to use the website.

---

## 1. Getting Started

Before you begin, ensure you have your course evaluation data file ready. Currently, the portal accepts `.json` data files. You can find this file inside the drive folder with your initials.

## 2. Accessing the Portal

Open your preferred web browser (Google Chrome, Safari, or Edge) and navigate to the link provided to you. 

## 3. Uploading Your Data

Once the website loads:
1. Locate the **Upload** area on the main screen.
2. Click the upload button or drag-and-drop your course evaluation file into the box.
3. The dashboard will instantly process your file and generate your personalized view.

## 4. Navigating the Dashboard

Once your data is loaded, you will see a few key areas:

* **Performance Overview:** At the top, you will see your overall ratings and key metrics for the course.
* **Organized Student Comments:** The system uses a smart filter to automatically remove administrative survey questions and boilerplate text. You will only see the actual, meaningful feedback written by your students, categorized for easy reading.
* **Visualizing Trends:** Depending on the data provided, you may see charts breaking down student engagement, assignment effectiveness, and learning resources.
